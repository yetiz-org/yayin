# 夜音

Apple Silicon Mac 的原生注音輸入法，使用標準／大千鍵位，提供中英混輸與繁簡輸出。

## 下載與安裝

最低需求：Apple Silicon、macOS 26.0。

1. 前往[最新版本](https://github.com/yetiz-org/yayin/releases/latest)，下載 `YAYin-X.Y.Z.dmg`。
2. 打開磁碟映像，把「夜音」拖到「應用程式」。標準帳號無法拖入時，請放到個人資料夾內的「應用程式」。
3. 開啟「應用程式」裡的夜音，第一次開啟時按「打開」。夜音會為目前帳號裝好輸入法，不需要密碼。
4. macOS 詢問是否允許夜音時，請按「允許」，夜音就會啟用並選取。沒有看到詢問，或夜音提示還差一步時，請在已開啟的「鍵盤」設定按「文字輸入」的「編輯」，再按「＋」搜尋「夜音」並加入，然後回到夜音選「啟用夜音」。
5. 若曾直接把夜音丟到垃圾桶，重新安裝時夜音會請你在「鍵盤」設定的清單選夜音按「−」，再回到夜音按「繼續」，之後照第 4 步允許即可。

手動安裝只需下載 `.dmg`；同版的 `.zip`、`manifest.json` 與 `manifest.json.sig` 供 App 內更新使用。

## 更新

夜音每天最多檢查一次新版，檢查不傳送個人資料，可在設定關閉。有新版時會跳出更新視窗，按「立即更新」即可，不需要密碼；完成後夜音自動重新開啟。更新前請先完成或取消正在輸入的文字。

## 移除

開啟夜音，選「移除夜音…」並確認，不需要密碼。夜音會打開「鍵盤」設定，請按「文字輸入」的「編輯」，在清單選夜音按「−」，再回到夜音按「繼續移除」。移除會刪除目前帳號的夜音輸入法、個人詞與設定，請先用「備份個人資料」備份。
