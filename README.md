# 夜音

夜音是一款快速、好用的 Mac 注音輸入法，讓打字更順手。

- **中英文一起打**：自動辨識中英文，不用一直切換。
- **越用越懂你**：學習你常用的詞語和選字習慣。
- **繁體、簡體自由切換**：依照需要選擇輸出方式。
- **多台 Mac 都能用**：可自行選擇同步個人詞語與設定。

## 下載與安裝

夜音適用於搭載 Apple 晶片的 Mac，需要 macOS 26 或以上版本。

1. 到[下載頁面](https://github.com/yetiz-org/yayin/releases/latest)，下載檔名以 `.dmg` 結尾的夜音。
2. 打開下載的檔案，將「夜音」拖到「應用程式」。無法拖入時，請放到個人資料夾內的「應用程式」。
3. 打開「應用程式」裡的夜音，第一次開啟時按「打開」。
4. 如果系統詢問是否允許夜音，請按「允許」。接著就可以切換到夜音開始輸入。

如果沒有看到允許提示，或夜音提示還差一步，請依畫面指示到「系統設定」的「鍵盤」中加入夜音。

如果曾直接把夜音丟進垃圾桶，請先依畫面指示移除舊的輸入法紀錄，再重新加入。

## 更新

有新版時，夜音會提醒你；按「立即更新」即可。你也可以在設定中關閉更新檢查。更新前請先完成或取消正在輸入的文字。

## 移除

打開夜音，選擇「移除夜音…」，再依畫面指示操作。移除時會刪除這個帳號的個人詞語和設定，請先使用「備份個人資料」保存。

## 資料授權

夜音使用的部分詞庫與字典來自 McBopomofo、OpenCC 和 SCOWL；完整授權聲明隨夜音提供。
